# Heyy Studio Architecture Workflow v2

## Locked direction
- OpenAI remains the preferred Architecture image provider after architect review of OpenAI vs Gemini plan samples.
- Architecture/Interior remain concept-development products, not technical documentation.
- Plan Foundation cost/latency optimization (Terra/Luna configuration) remains compatible with this workflow.

## 1. Design Direction
Each selected Design Direction image is now one coordinated multi-view board rather than one rear/pool glamour image. The board asks for four studies of one proposal: primary frontage/arrival, important secondary side, oblique aerial/massing overview, and material/detail studies. The exact wording adapts by project family so restaurants, offices, towers, healthcare, education, industrial and custom projects are not forced into residential logic.

## 2. Orientation lock
New Canonical Plan Specifications include `orientation_lock` with a north-up coordinate convention, primary and secondary frontage edges/roles, no-mirror rule and fixed anchors. Plan prompting explicitly translates viewpoint evidence into cardinal site relationships before placing rooms. This is intended to stop garage/service, pool/amenity and frontage relationships from flipping between Direction, Plan and Visuals.

## 3. Concept Visuals
Build-from-scratch projects now receive four coordinated visual briefs:
1. Primary frontage / arrival view
2. Secondary frontage / important site edge
3. Project-type-appropriate spatial experience
4. Architectural detail / material collage

The titles/prompts adapt to residential, hospitality, workplace, large/mixed-use, institutional, industrial and custom contexts. OpenAI image generation receives the approved Plan Foundation plus selected Direction and must preserve orientation.

## 4. Architectural Style
- Added: Modern
- Removed: Modern Arabic

## 5. Backward compatibility
Older two-view projects continue to display their existing visual types. New four-view prompts replace obsolete visual rows only when Concept Visual briefs are refreshed. Existing Plan-to-Visual workflows continue to use uploaded drawings as geometry authority and may keep user-selected camera views (up to four).
